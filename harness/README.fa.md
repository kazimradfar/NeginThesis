# ابزار بررسی پایان‌نامه (Harness)

این ابزار یک اسکریپت کوچک است که پیش‌نویس پایان‌نامه (`Full Draft/VMAT-TBI_MSc_Thesis_Full_Draft.docx`) را با فایل منابع (`Reference/VMAT-TBI_thesis_references.ris`) مقایسه می‌کند و فهرست کارهای ناتمام را نشان می‌دهد. فقط به پایتون (نسخه 3.8 یا بالاتر) نیاز دارد، بدون اینترنت کار می‌کند و به هیچ حساب یا کلید API نیازی ندارد.

نسخه انگلیسی راهنما: [README.md](README.md)

## نحوه اجرا

در پوشه اصلی مخزن (در PowerShell، Command Prompt یا ترمینال لینوکس/مک) این دستور را اجرا کنید:

```
python harness/check_thesis.py --lang fa --out harness/report.fa.md
```

گزارش فارسی روی صفحه نمایش داده می‌شود و در `harness/report.fa.md` ذخیره می‌شود. برای گزارش انگلیسی، گزینه `--lang fa` را حذف کنید.

گزینه‌های دیگر:

- `--docx` و `--ris`: مسیر فایل‌های دیگر به جای فایل‌های پیش‌فرض
- `--strict`: اگر هر هشداری وجود داشته باشد، اسکریپت با خطا (کد 1) پایان می‌یابد

## چه چیزهایی بررسی می‌شود

| بررسی | سطح |
|---|---|
| ارجاعی مانند `(17)` یا `(3-5)` که به شماره منبعِ ناموجود اشاره می‌کند | خطا |
| منبعی که در متن هیچ‌جا ارجاع داده نشده است | هشدار |
| منبعی که ترتیب اولین ارجاع آن به‌هم ریخته است | هشدار |
| جاافتادگی در شماره‌گذاری منابع یا منابع تقریباً تکراری | هشدار |
| تفاوت فهرست منابع پیش‌نویس با فایل RIS (تعداد، یا منابع ناموجود در یکی از دو طرف) | هشدار |
| موارد `[TO BE CONFIRMED]` که هنوز تأیید نشده‌اند، به تفکیک بخش | هشدار |
| جدول‌هایی که هنوز مقدار مورد انتظار دارند (`green = expected values`) | هشدار |

کد خروجی: اگر خطایی وجود داشته باشد (یا با `--strict` هر هشداری)، مقدار `1`؛ در غیر این صورت `0`.

## اجرای آزمون‌ها

```
python -m unittest discover -s harness/tests -v
```

## نکته‌ها

- فایل‌های `report.md` (انگلیسی) و `report.fa.md` (فارسی) تصویر لحظه‌ای هستند که توسط اسکریپت ساخته می‌شوند. بعد از ویرایش پایان‌نامه، اسکریپت را دوباره اجرا کنید تا به‌روز شوند.
- عنوان بخش‌ها و متن موارد `[TO BE CONFIRMED]` همان‌طور که در پایان‌نامه انگلیسی نوشته شده‌اند، به انگلیسی نمایش داده می‌شوند.
- اگر در یک جمله فهرستی به شکل «(1) ... (2) ...» نوشته شده باشد، ابزار آن را اشتباهاً ارجاع می‌شمارد و ممکن است هشدار نادرست بدهد.
- فهرست `[TO BE CONFIRMED]` و فهرست مقادیر مورد انتظار، همان فهرست کارهای باقی‌مانده برای تکمیل پایان‌نامه است. هر بار که مقداری تأیید یا اندازه‌گیری شد و نشانه آن را حذف کردید، تعداد موارد در گزارش کم می‌شود.
